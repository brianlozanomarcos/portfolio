Docker

Una herramienta con la que trabajar con contenedores y no vm.

Contenedor= Forma de virtualizacion de un sistema operativo app.

Instalacion

[sudo aot install docker.io]

Portainer

Portainer

Contenedor para administrar los contenedores docker con un entorno grafico y sencillo, via web.

Instalación

 docker volume create portainer_data

Esto creará un volumen persistente.

 docker run -d -p 9000:9000 --name=Portainer --restart=always -v /var/run/docker.sock -v portainer_data:/data portainer/portainer

Jenkins

Jenkins

Es un servidor de automatizacion open source. Lo puedes instalar tanto en servidor normal o por docker

Instalación Docker

docker run -p 8080:8080 -p 5000:5000 -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts -jdk11

Esto creará y levantará el contenedor Jenkins.

 docker logs id-contenedor

Esto nos mostrará las credenciales.

Gitea

Gitea

Servicio de alojamiento de repositorios de codigo abierto, alternativa a github en local.

Instalación Docker

docker volume create create gitea_data

Esto creará un volumen persistente.

 docker run -d --name=gitea -p 3000:3000 -p 222:22 \ -v gitea_data:/data \ gitea/gitea:latest

Esto nos creara y levantara el contenedor Gitea.
